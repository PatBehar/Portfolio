CASEFLOW LAB 03

Knowledge Assistant

Retrieve policy passages with exact citations, abstain when evidence is missing, and keep generation separate.

LOCAL EXTRACTIVE MODE · SYNTHETIC DOCUMENTS

CF03 dashboard and recorded walkthrough

Recorded from the working local prototype · BM25 retrieval and extractive answers · no Groq request.

Complete recorded walkthrough

01 / BUSINESS CONTEXT

Answer policy questions only from supporting evidence

Service operations · fictional policy library

Operators need to find the current policy passage that applies to a request, distinguish it from superseded guidance and know when the local corpus cannot support an answer.

The local knowledge base is synthetic; it is not an organization’s actual policy repository.

  • Stale guidance

    A superseded passage should not be treated as the current rule.

  • Unsupported answers

    Insufficient retrieval evidence should lead to abstention.

  • Citation drift

    A citation should match the exact text and offsets in its source.

02 / PROCESS DESIGN

Original process and architecture diagrams

These exports document manual policy lookup, a proposed cited retrieval workflow and the local knowledge architecture. Diagram files remain original source exports.

03 / IMPLEMENTED FLOW

Local retrieval with exact, inspectable citations

The application indexes synthetic source passages with BM25, ranks candidates and extracts evidence with exact source offsets. The recorded path stays in offline/extractive mode.

  1. 01

    Choose a scenario

    Load a synthetic question about a policy or service process.

  2. 02

    Retrieve passages

    Rank the local document chunks with BM25; scores order results and are not confidence.

  3. 03

    Cite or abstain

    Return exact source text or abstain when evidence is missing, conflicting or untrusted.

  4. 04

    Inspect the sources

    Review document status, retrieved evidence and the local request trace.

Evidence and generation boundary

  • Citations are checked against the exact document text and start/end offsets.
  • Superseded, conflicting, untrusted or insufficient evidence is not presented as a supported answer.
  • No generation button is used in this recording; Groq credentials are not read and no provider request is made.

Local FastAPI + SQLite and an in-memory BM25 index · 11 synthetic documents / 22 passages · no external inference.

04 / TECHNICAL CHOICE

Retrieval and optional generation stay separate

The default answer path is extractive: it returns evidence directly from the local corpus. A separate opt-in provider path exists in the source, but it is not required or used for this demo.

A historical Groq test request is documented in the source project; this recording makes no model call.

Prototype stack

  • Python 3.12
  • FastAPI
  • BM25 retrieval
  • Exact extractive citations
  • SQLite
  • Local synthetic corpus
  • Optional provider path · disabled

Prototype boundaries

  • No live Groq call, generated answer, customer outcome or knowledge-accuracy claim.
