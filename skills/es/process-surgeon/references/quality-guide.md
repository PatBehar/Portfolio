# Controles de calidad

1. Cada afirmación material tiene una fuente o se marca como hipótesis/supuesto sintético.
2. El agente transforma la entrada; no se limita a entregar consejos genéricos.
3. El resultado es utilizable, con responsable y criterios de aceptación.
4. Datos faltantes o dudosos se marcan antes de calcular o recomendar acciones sensibles.
5. No se declara una integración/llamada ejecutada sin salida verificable.
6. Exigir aprobación humana para escrituras, comunicaciones y acciones sensibles.
7. Pruebas planeadas no equivalen a pruebas conductuales ejecutadas.
