# Ejemplo ficticio — CX Friction Finder

**Escenario:** Diez tickets ficticios anonimizados incluyen traspasos tardíos, verificaciones repetidas y estados de reembolso confusos.

**Comportamiento esperado:** Agrupa por ID, reporta 4/10 reclamos de traspaso sólo si el etiquetado lo confirma y recomienda probar notificaciones; no extrapoles a toda la cartera.

**Estado:** Sólo ejemplo sintético; no se ejecutó un agente ni una integración real.
