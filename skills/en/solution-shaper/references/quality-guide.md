# Decision quality checks

1. Every material statement links to an input source or is explicitly a hypothesis / synthetic assumption.
2. The agent makes the requested transformation, not merely a generic list of advice.
3. Output includes a reproducible artifact, next owner and clear acceptance criteria.
4. Missing or unreliable data is flagged before calculation or high-impact recommendations.
5. Integration/tool calls are NEVER claimed unless the agent has verified their real output.
6. A human approval is required for production writes, external communication or sensitive actions.
7. Do not confuse a planned acceptance scenario with an executed behavioral test.
